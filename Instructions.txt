How to Install (Recommended)	Windows: Open the Install folder and double-click 01-Install.bat.	Mac: Open the Install folder, right-click 01-Install.command, select Open, and allow it to run in the Terminal.Restart DaVinci Resolve.The tools will now appear in the top menu bar under Workspace > Scripts > Sync and Label Suite.How to Install (Manual Method)	If you prefer to install manually, copy the entire Auto Folder Sync & Media Color folder	into your user-specific DaVinci Resolve scripts directory:	Windows: %AppData%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility\	Mac: ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/How to Customize Your Settings	Double-click the included Config shortcut, or manually open Config.json in any text editor	(like Notepad or TextEdit) to customize the scripts for your workflow.	FOLDERS_TO_SYNC: 		Add the exact hard drive paths for the master folders you want to automatically import.	CAMERA_KEYWORDS:		Assign your specific camera names or keywords (e.g., "fx3" or "drone") to your preferred UI color.	CAMERA_LUTS:		Add the exact internal Resolve path for any LUTs you want applied automatically upon import or timeline sync.Available UI Colors	Orange, Apricot, Yellow, Lime, Olive, Green, Teal, Navy, Blue, Purple, Violet, Pink, Tan, Beige, Brown, Chocolate.Important Formatting Notes	Smart Matching:		The script automatically prioritizes longer, specific keywords (like "dji pocket 3") over generic ones (like "dji").		You do not need to worry about the exact top-to-bottom order in your configuration file.	Double Slashes:		When adding folder paths or LUT paths on Windows, you must use double backslashes (\\) so the code reads it correctly.	Commas:		When editing the Config.json file, ensure every line inside a list or group ends with a comma,		except for the very last item in that group. Missing commas will prevent the scripts from running.Tip:	Tip: Finding Your Exact LUT Path		Finding the exact internal LUT can sometimes be tricky.		Apply the LUT manually to the clip in your current bin, open Workspace > Console, click Py3 at the top of the window		to switch to Python, and paste this exact code:clips = resolve.GetProjectManager().GetCurrentProject().GetMediaPool().GetCurrentFolder().GetClipList()for clip in clips:    lut = clip.GetClipProperty("Input LUT")    if lut:        print(f"\nLUT PATH TO COPY:\n{lut}\n")        break		or if you want all clips in the bin:for clip in clips:    print(f"{clip.GetName()} -> {clip.GetClipProperty('Input LUT')}")		This will print out a list of your clips alongside their exact LUT paths.		Copy the path exactly as it appears (remembering to use double backslashes \\ for Windows) into your Config.json.
